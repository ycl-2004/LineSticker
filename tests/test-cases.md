# AI LINE Sticker Maker 測試案例

## 共通驗收

每個案例都要確認：

- 裁切數量正確。
- 編號順序是左至右、由上至下。
- 沒有漏圖或重複圖。
- 每張檔名為 `sticker_01.png` 形式。
- PNG 可以開啟。
- LINE 模式下寬度 ≤ 370 px、高度 ≤ 320 px，檔案大小 ≤ 1 MB 時顯示 `✓ 可用於 LINE`。
- 原尺寸與 2× HD 模式須標示為非 LINE 上架檔，不能顯示為 LINE 合規。
- 預覽中的編號沒有被繪製到 PNG 內容。
- 每張結果顯示檔名、像素尺寸與 LINE 合規狀態。
- 單張下載正常。
- 「下載 ZIP」會下載一個包含所有 PNG 的壓縮檔，解壓後檔名維持 `sticker_01.png` 形式。
- 重新開始後原始圖片、結果、進度與 Blob URL 清除。
- 調整格線、自動對齊、去背開關或清理模式後，既有結果立即清除，必須重新裁切。
- AI Prompt 按鈕會根據目前數量產生並複製 Prompt，不在 UI 展開完整 Prompt。
- Prompt 內包含目前網格、建議尺寸、單格尺寸與對應文字。
- Prompt 明確禁止圖片出現數字、編號、Logo、浮水印與跨格內容。

## 解析度控制測試

- 預設「高清」24 張時，確認 Prompt 與建議尺寸為 `2048 × 3072 px`、每格 `512 × 512 px`。
- 切換「標準」後，確認同步變為 `1024 × 1536 px`、每格 `256 × 256 px`。
- 切換「主檔」後，確認同步變為 `4096 × 6144 px`、每格 `1024 × 1024 px`。
- 上傳每格約 256px 的來源，確認出現不足所選來源品質與「放大不會補回真實細節」提示。
- LINE 模式裁切後，確認仍符合 370 × 320 px 與 1 MB 檢查；切換「原尺寸」與「2× HD」後，確認結果標示為非 LINE 上架檔，且 HD 檔名附有 `_hd`。

## 錯誤與隱私測試

- 上傳不支援格式，確認顯示格式錯誤。
- 上傳低解析度圖片，確認顯示解析度提醒但不會假裝提高畫質。
- 分別在 8、16、24、40 張模式上傳比例不符的圖片，確認會顯示比例提醒，但裁切按鈕仍可使用，且能依所選張數完成裁切。
- 上傳透明 PNG，確認輸出仍有透明背景並執行 Trim。
- 上傳白底 PNG 或 JPG，確認「移除近白背景」預設為勾選，裁切輸出角落 alpha 變成透明。
- 關閉「移除近白背景」後重新裁切，確認白色背景會保留。
- 開啟瀏覽器 Network 面板，確認沒有圖片上傳 API、AI API 或雲端儲存 API 請求。
- 點擊首頁雲端資料夾連結，確認只開啟指定網址，不讀取其內容。

## 裁切預覽與去背操作

- 上傳圖片後確認出現「確認裁切（預覽）」與目前網格。
- 確認裁切預覽以紅色邊緣帶＋白色襯底的粗實線及「最終裁切外框」標籤表示圖片外框；內部可調格線使用白色襯底、粗深青色虛線與橘色拖曳點，兩者在白色或複雜圖片上都能立即區分。
- 在預覽圖上分別拖曳一條垂直線與一條水平線，確認只有該條邊界移動，且裁切結果使用新位置。
- 確認拖曳後相鄰格不會小於 32 px。
- 點擊「重設網格」，確認所有格線回到標準等分位置。
- 對有 2–4 px 中性灰分隔線、但列高稍不等距的來源，確認上傳後會自動對齊可見分隔帶；點擊「自動對齊」可重試。
- 對沒有分隔線的規則網格與整片均勻灰底來源，確認自動對齊不會把格線移到搜索範圍邊緣。
- 對白底 PNG 確認「移除近白背景」預設已開啟，輸出 PNG 角落 alpha 變成透明，且尺寸仍不超過 370 × 320 px。
- 智能模式使用「灰白背景＋深色封閉輪廓內白色物件」fixture，確認外部背景透明、封閉白色物件仍為不透明。
- 強力模式重跑同一 fixture，確認封閉白區會被清除，且 UI 明確提示可能影響眼白與白色道具。
- 手動關閉「移除近白背景」後重新裁切，確認輸出角落恢復為不透明白色。
- 重新開始後確認圖片資訊、裁切預覽、網格位移與去背勾選狀態都清除。
