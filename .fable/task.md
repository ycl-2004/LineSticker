# LINE Sticker Cutter — Adaptive cleanup and verified 40-grid output

## Goal

让裁切器稳定处理低解析度 JPEG、可见分隔线、不规则网格和白底文字，并用用户提供的 40 格来源图产出可观察的前后改善结果。

## Acceptance criteria

- [x] 可调或自动清除 2–4 px 分隔线，不让残留格线阻止 Auto Trim。
- [x] 近白去背使用自适应背景判断与柔化边缘，显著减少文字周围白边。
- [x] 提供保守／强力清理模式；强力模式可处理与外缘不连通的白色孤岛，并明确提示误删白色物件的取舍。
- [x] 裁切后检查白底残留与内容触边，结果卡显示可操作的质量警告。
- [x] 透明 PNG、保留白底、8／16／24／40 张及 LINE／原尺寸／2× HD 既有流程不回归。
- [x] 规则等分网格与原本可正常处理的图片维持既有裁切结果；未写入任何针对本次图片尺寸、张数或格线坐标的特例。
- [x] 使用 `1985b75b-6382-4fd3-ab00-2b71c4a50a8d.jpeg` 实际完成 40 张裁切；`sticker_23` 不再保留整块白底，代表性文字白边和分隔线明显改善。
- [x] 语法、差异、算法测试和浏览器实际流程均有证据。

## Requirements (append-only)

1. 修复本批输出中白底、白边、分隔线残留、Auto Trim 失效和部分内容触边的问题。
2. 优化必须适用于所有贴图张数，不只当前 40 张。
3. 用用户提供的原图实际跑一次，让用户看到改善后的效果。
4. 修复必须是可复用的通用设计，不能只服务当前图片，也不能破坏最基本的规则网格／透明 PNG 使用流程。

## Decision log

- 2026-08-13：不采用单纯降低固定白色阈值或固定扩大裁切内缩；两者会误删眼白／白色道具或切掉已贴边内容。
- 2026-08-13：以可调边缘清理、自适应背景色、柔化 alpha、可选强力清理和结果 QA 组合处理；默认保持较安全的自动模式。
- 2026-08-13：用户提供的 40 格 JPEG 仅作为回归 fixture；检测逻辑只依赖当前网格与像素特征，不使用硬编码尺寸、张数或坐标。
- 2026-08-13：智能模式只从每格外缘 flood-fill 近白候选，以保留封闭白色物件；强力模式才清除所有近白候选。
- 2026-08-13：分隔线必须同时符合连续度、相对背景峰值差与最大带宽，避免均匀灰底被误认成格线。
- 2026-08-13：来源上传时只扫描一次完整 RGBA，之后仅保存宽度＋高度规模的分隔线评分数组；不长期保存完整像素副本，避免 5120 × 8192 主档额外占用约 160 MB。

## Evidence

- 基线来源为 896 × 1195 JPEG，无 alpha；实际行高为 164／163／155／140／149／143／145／136 px。
- 基线输出 40／40 保留完整行高，36／40 有不透明像素触碰成品边缘，22／40 保留完整格宽。
- `sticker_23.png` 基线 98.7% 画布不透明；实际裁切只移除 334 个外缘连通白点，约 15,366 个近白点被分隔线封闭而保留。
- 浏览器实测真实 JPEG：自动对齐 11 条分隔线，40／40 张完成；全批平均残余近白 0.13%，最高 0.46%，`sticker_23` 残余近白 0.08%。
- 真实输出中 26 张标示“来源内容碰到格线”；这些文字／角色在来源 JPEG 已贴近或穿过分隔线，属于不可重建的来源质量提示。
- 程序化规则 fixture：智能模式的 8／16／24／40 张分别完整输出，均为 68 × 68、透明角落、封闭白色中心保留、0 质量警告。
- 透明 24 张 fixture 保留 alpha；关闭去背的 8 张 fixture 保留不透明背景；强力模式会清除封闭白色中心。
- 均匀灰底按“自动对齐”回报未检测分隔线并保留 2 × 4 网格；真实图回报 11 条可见分隔线。
- LINE／原尺寸／2× HD 回归首张分别为 `sticker_01.png` 68 × 68、`sticker_01_master.png` 68 × 68、`sticker_01_hd.png` 136 × 136。
- 390 px 视窗回归发现并修复长文件名撑宽单列 Grid；修复后 `scrollWidth === clientWidth`，新增清理控件完整落在视窗内。截图：`/tmp/line-sticker-mobile-controls-fixed.png`。
- 静态检查通过：`node --check app.js`、`git diff --check`。浏览器结果截图：`/tmp/line-sticker-fixed-results.png`。
